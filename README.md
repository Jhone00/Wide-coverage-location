Wide Coverage Location 🚗

Esse foi meu terceiro projeto. Fiz uma landing page sobre viagens compartilhadas, com header de navegação, logo, título e um texto convidando a pessoa a aproveitar tudo o que a cidade oferece através do app, além de um botão de chamada pra ação.

Tecnologias que usei 💻
HTML
CSS
Objetivo

Nesse projeto meu foco foi praticar estruturação de página e estilização com CSS, trabalhando layout e organização de conteúdo de forma simples e direta.

Preview

Header com menu e botão de cadastro, logo, título "Wide coverage location", texto de apresentação sobre viagens compartilhadas na cidade e botão "Learn more".
